# Dedicated 480i build

`MAC_TV525` selects a fixed 27 MHz, 525-line interlaced output.
Remove it and rebuild for native progressive output. Guest V8 timing stays
native in either build. HDMI scales the interlaced stream; there is no
independent native HDMI stream or runtime output toggle in this profile.

`sys` must match upstream unchanged. The core supplies RGB, HS, VS, DE and
field parity through standard ports. Stock OSD and RGB/component conversion
run downstream. Composite sync comes from the framework and differs from
the custom diagnostic encoder; its CRT behavior requires hardware testing.

The RGBx store uses [0x21800000,0x21c00000). A core-owned bridge splits
128-bit canvas bursts into 64-bit DDRAM bursts of at most 128 beats.
The pipeline owns the idle DDRAM port at 65 MHz and drains accepted bursts
across guest reset. ASCAL keeps its own framework port. Native capture
includes the IIe status overlay. Deflicker offers Strong (default), Mild and
Off; changes take effect at the next source frame.

Short checks, from the repository root:

```sh
make -f tests/iie/tv525.mk check
python3 tests/iie/check_tv525_integration.py
python3 scripts/osd_check.py
```

Before a PR: compile both macro variants, review TimeQuest results, and test
scaled HDMI OSD, both CRT fields, component/composite sync, de-flicker,
monitor changes and guest reset. No hardware qualification
is implied by simulation results.
